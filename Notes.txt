Forgot password
===============
Vendor clicks "Forgot Password"
        ↓
Enters registered email
        ↓
Backend finds Vendor
        ↓
Generate secure random reset token
        ↓
Store HASHED token + expiry in MongoDB
        ↓
Send reset link through email
        ↓
User clicks link
        ↓
React opens /reset-password/:token
        ↓
User enters new password and confirm password
        ↓
Backend hashes token and verifies it
        ↓
Update password
        ↓
Delete reset token
        ↓
User logs in with new password

Making FoodStack Distributed system.

1. Make Application stateless.
        ->Any backend instance should be able to handle any request without depending on data stored inside that particular Node.js process.

        What we're trying to achieve

        After Step 1, your FoodStack should look conceptually like this:
                   FOODSTACK
                       │
                       ↓
                  React Client
                       │
                       ↓
                 Node/Express
                       │
            ┌──────────┼──────────┐
            ↓          ↓          ↓
         MongoDB     Redis    Cloudinary
            │          │          │
         Data       Sessions     Images
